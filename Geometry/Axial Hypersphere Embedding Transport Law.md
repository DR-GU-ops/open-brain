# Axial Hypersphere Embedding Transport Law

> **Lock sentence:** A DR-GU embedding is not merely placement into a vector space. It is governed transport from a global Omega ledger through an ultrametric nest into a local witness surface, preserving hypersphere source/target, hypersphere chart, axial-time basis, rotor frame, orientation sign/chirality, transport operator, overlap region, projection surface, return path, defect residual, and Omega admissibility. T1, T2, and T3 axial times are not interchangeable scalar time labels; they are regime-relative time bases for distinct hypersphere embeddings.

## The Nine Embedding Rules

### 1. Embedding is transport, not placement
`embedding_is_transport_not_placement`
A DR-GU embedding is governed transport through source/target hypersphere regimes, not mere insertion into vector space.

### 2. Hypersphere source and target are required
`hypersphere_source_target_required`
Every embedding must declare the source hypersphere and target hypersphere — e.g. S1 complex Hilbert, S2 quaternionic rotor/Hamilton, or S3 ultrametric state space.

### 3. Axial time basis is not interchangeable
`axial_time_basis_not_interchangeable`
T1, T2, and T3 are regime-relative axial-time bases. Cross-hypersphere comparison must preserve which axial time is active and how it transports.

### 4. Rotor frame required for oriented embedding
`rotor_frame_required_for_oriented_embedding`
Any embedding crossing rotor/hypersphere regimes must preserve rotor frame, axis/plane, handedness/chirality, orientation sign, and composition order.

### 5. Overlap region permits comparison, not identity
`overlap_region_permits_comparison_not_identity`
Overlap between hyperspheres permits comparison only through a declared overlap region, transport operator, and return path. It does not prove identity.

### 6. Projection surface is witness, not object
`projection_surface_is_witness_not_object`
A local projection surface is a red-corridor witness surface of the deeper object, not the object itself. See [[Platonic Form-Participation Projection Law]].

### 7. Return path required for embedding admissibility
`return_path_required_for_embedding_admissibility`
No embedding is admissible unless its local readout can reconstruct back to source/object/relation candidates through a declared return path. See [[Bidirectional BST Embedding Guardrail]].

### 8. Dimensionless embedding readout requires orientation warrant
`dimensionless_embedding_readout_requires_orientation_warrant`
Dimensionless readouts (cosine similarity, normalized score, angle, phase, correlation) require orientation basis, unit cancellation/normalization proof, and hypersphere chart. See [[Dimensionless Measurement Rotor-Hypersphere Law]].

### 9. Omega admits cross-hypersphere embedding
`omega_admits_cross_hypersphere_embedding`
No local vector, scalar score, projection surface, similarity, or hypersphere coordinate self-canonizes. Omega admits, scopes, preserves tension, or bottoms the embedding after transport-warrant review.
