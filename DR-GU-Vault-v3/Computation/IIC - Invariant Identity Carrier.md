# IIC — Invariant Identity Carrier

> **Lock sentence:** IIC is relational, not scalar. It is the invariant carrier of relational identity preserved across admissible transformations — a conjugate pair, not a label.

## Definition

The IIC is a **conjugate pair**:

```text
IIC(S) := (TS, RS)
```

Where:
- `TS` = Taylor-side / local / compression carrier
- `RS` = Rodger-side / global / return-twist carrier

Identity is carried by the **pair**, not by `TS` alone or `RS` alone.

## What IIC Is Not

```text
IIC ≠ one scalar value
IIC ≠ one bit
IIC ≠ one coordinate
IIC ≠ one table cell
IIC ≠ a label
```

## What IIC Is

```text
IIC = preserved relational coherence between paired descriptions
IIC = what remains invariant when r, θ, torsion, curvature, projection, or scale are transformed lawfully
IIC = the primitive computational object from which bits are read out
```

## The Dyadic Primitive

The IIC is at minimum **dyadic**. A single isolated scalar is underdefined. The minimum relational identity unit is:

```text
dyad = (E(h), B(h))
```

Where:
- `E(h)` = harmonic compression carrier
- `B(h)` = harmonic return-twist carrier
- Ω regulates the dyad; it is not a co-equal third primitive

The IIC must survive Δ-consistency testing:

```text
Δ = 0  →  No-Drift  →  identity preserved
Δ ≠ 0  →  Drift detected  →  route to Ω audit
```
