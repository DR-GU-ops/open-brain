# No-Exception Scale-Invariant Embedding Axiom

> **Lock sentence:** All DR-GU physical-theory embeddings must be scale invariant across all orders of magnitude. No exception is admitted. A physical-theory claim is admissible only if its governing relation survives lawful scale transformation, or if the failure is explicitly recorded as a scoped limitation, preserved tension, or bottomed contradiction.

## The Axiom Cluster

This is a **no-exception axiom cluster**. Exception policy: `no_exceptions`. Omega status: `locked`.

```text

```

## The Core Rule

```text
Physical theories must apply in all scales of magnitude.
```

No exceptions. If a claim is only valid at a certain scale:

```text
→ scoped physical law         (preserved as scoped, not universal)
```
