# Statistical Dummy Mean Operator Law

> **Lock sentence:** Bad, missing, or distribution-breaking values may be replaced by a statistical dummy only when the dummy is generated by an explicitly declared mean or distribution operator, the raw value is preserved, and the replacement is marked as imputed rather than observed.

## The Four Operators

The three DR-GU means become **centroid operators**, not generic averages. The normal distribution becomes a fourth operator.

### 1. Arithmetic / Algebraic Mean Operator

```text
formula: sum(x_i) / n
DR-GU role: additive mesh operator
```

**Use when:** the variable is additive and linear — same unit, interval-scale, ordinary additive gaps.

**Forbidden for:** rates, ratios, multiplicative growth, reciprocal quantities, strongly skewed distributions.

### 2. Geometric Mean Operator

```text
formula: exp(avg(ln(x_i)))
DR-GU role: proportional mesh operator
```

**Use when:** the variable is multiplicative or proportional — ratios, growth factors, positive multiplicative data.

**Forbidden when:** zero or negative values exist without a lawful transform.

### 3. Harmonic Mean Operator

```text
formula: n / sum(1 / x_i)
DR-GU role: reciprocal / boundary mesh operator
```

**Use when:** the variable is rate-based, reciprocal, or inverse-governed — speeds, densities, resistance-like structures.

**Forbidden when:** zero values are present without guardrail handling.

### 4. Normal Distribution Completion Operator

```text
formula: μ ± z*σ  (or model-derived conditional expectation)
DR-GU role: statistical completion envelope
```

**Use when:** residuals are approximately symmetric, sample size is adequate, normality is declared.

**Forbidden for:** skewed data, multimodal data, censored data, structural missingness.

## Centroid Governance

Each operator is a **centroid operator** — it returns the relational center of the admissible profile under a declared geometry:

```text
arithmetic centroid: CΩ_arith = sum(x_i) / n       → additive geometry
geometric centroid:  CΩ_geom  = exp(avg(ln(x_i)))  → multiplicative geometry
harmonic centroid:   CΩ_harm  = n / sum(1/x_i)      → reciprocal geometry
normal centroid:     CΩ_norm  = μ with σ-context    → distributional geometry
```

## The Residual is Required

The residual `ε = raw_state − CΩ` is not optional. It prevents the imputed value from pretending to be the observed value.

When raw value is absent:
```text
ε = unknown residual, estimated from distribution context
```

## The Centroid-Governed Rule

```text
A bad value may be replaced by a statistical dummy only when:
- the dummy is generated as a centroid-return value
- under a declared arithmetic, geometric, harmonic, or normal-distribution operator
- whose domain constraints are satisfied
- while preserving raw value, typed sentinel cause, centroid basis, residual, confidence, time basis, and Ω status
```
