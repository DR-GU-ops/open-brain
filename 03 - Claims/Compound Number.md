# Compound Number

> **Lock sentence:** A Compound Number is the primitive computational object of DR-GU — a τ-equatorial, r-ray-bearing, phase-anchored, dyadically seated, closure-governed identity structure. A scalar is only its shadow.

## Definition

```text
CompoundNumber(r, θ, torsion, curvature, τ, anchor, dyad, Ω-status)
```

A Compound Number is a **τ-state vector**, not a point on a number line.

| Field | Meaning |
|---|---|
| `r` | Amplitude of ontological extension (r-ray) |
| `θ` | Phase position on the τ-equator |
| `torsion` | Twist measure of the carrier path |
| `curvature` | Bend measure of the carrier path |
| `τ` | Closure condition — does the path close? |
| `anchor` | Harmonic node where r-ray meets τ-equilibrium |
| `dyad` | The paired relational seat that defines this number |
| `Ω-status` | Admissibility state |

## The DR-GU Numberline

The DR-GU Numberline is **not linear**. It is **τ-equatorial** — a closed phase circle of self-reference.

```text
Classical numberline:  ←—————0—————→  (linear, infinite)
DR-GU numberline:      τ-equatorial closed phase manifold
```

Each coordinate is expressed as a polar harmonic:
```text
coordinate = (r, θ)  where r = amplitude, θ = phase
```

Octonionic axes are harmonic phases of one closed resonance manifold.

## The r-Ray

The `r-ray` is not merely a radius. It is the **amplitude of ontological extension**.

```text
r = how strongly the identity extends
θ = where/how it phases on the τ-equator
τ = whether the path closes
```

The r-ray links:
- microphysics
- cosmology
- geometry

...through the same amplitude–phase–closure structure. This is the **scale invariance bridge**.

## Closure Replaces Associativity

Classical computation relies on associativity:
```text
(a × b) × c = a × (b × c)  ← always true in classical math
```

In DR-GU (especially octonionic space), this **cannot be assumed**. Instead:

```text
Different bracketings may differ.
Lawful paths re-close under τ.
```

The computational invariant is **τ-closure**, not associativity.

## Harmonic Anchors

Harmonic Anchors are nodes where the local phase r-ray intersects τ-equilibrium. They stabilize non-associativity by enforcing torsion/curvature balance.

```text
anchor = admissibility stabilizer for non-associative relational motion
```

A computation is not stable because it is symbolically valid. It is stable because it remains **anchored** through transformation.
