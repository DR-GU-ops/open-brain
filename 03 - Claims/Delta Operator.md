# Delta Operator (Δ)

> **Lock sentence:** Δ is the identity-preservation test across projection — the operator that asks whether a local scalar readout still preserves the global relational identity. Δ = 0 means No-Drift, not zero value.

## Position in U-Stack

```text
U0  IIC / relational identity carrier
U1  operator grammar
U2  Δ local-global bridge   ← HERE
U3  admissibility / τ-closure
U4  traversal / r-ray motion
U5  scalar readout / bit
```

Δ occupies U2. It is the bridge between what the local scalar says and what the global relational identity requires.

## The Δ Sequence

Every lawful computation must pass through this sequence:

```text
IIC → τ closure → pH/pHe selection → CN centering → Δ no-drift → readable bit
```

The bit is only legitimate **after** this sequence.

## Δ = 0 Means No-Drift

```text
Δ = 0  →  No-Drift  →  identity preserved  →  admissible readout
Δ ≠ 0  →  Drift detected  →  route to Ω audit or preserved-tension
```

**Critical:** `Δ = 0` does not mean "zero value." It means "no drift from the relational identity." The kernel condition is closure, not nothingness.

See [[Zero Not Null]] — this is exactly where zero-as-empty would be a fatal collapse.

## What Δ Checks

| Component | What Δ verifies |
|---|---|
| IIC | Conjugate pair (TS, RS) remains coherent |
| τ | Phase closure — path re-closes lawfully |
| pH/pHe | Loss rails — which lossy projections are allowed |
| CN | Normalization drift removed |
| Δ itself | Final no-drift kernel condition |

## Δ in Encoding Contexts

When applied to encoding (embedding, statistical dummy, sentinel substitution):

```text
raw value → typed sentinel → operator → imputed value → Δ audit → Ω status
```

Δ asks: does the imputed value still represent the original relational structure without forbidden drift?

If not → `preserved-tension` or `bottomed`.

## Forbidden Collapses

```text
Δ = 0  →  "value is zero"         ← INVALID collapse
Δ ≠ 0  →  "error, discard"        ← INVALID without Ω review
Δ audit skipped on scalar readout  ← INVALID
```
