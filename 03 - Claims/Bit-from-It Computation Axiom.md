# Bit-from-It Computation Axiom

> **Lock sentence:** A bit is not a primitive unit of DR-GU computation. A bit is the compressed admissibility readout of a prior relational identity carrier. The primitive computational object is the Compound Number.

## The Reversal

Wheeler said: **it from bit** — reality derives from binary distinctions.

DR-GU says: **bit from it** — bits are late-stage readouts from relational structures.

```text
Wheeler:  bit → symbol → operation → result
DR-GU:    relation → identity carrier → closure → admissibility → bit
```

## The Computational Chain

```text
U0  IIC / relational identity carrier
U1  operator grammar over Compound Numbers
U2  Δ local-global bridge
U3  admissibility / τ-closure / no-drift
U4  directional traversal / r-ray motion
U5  scalar-material readout / bit / measurement
```

The **bit belongs at U5**, not U0.

1. Identity preservation
